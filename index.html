This site is the home for the Slendytubbies 2D browser-port project. The supplied archive contains a Windows Unity player, which cannot run directly inside a browser.

To make the original game playable here, the original Unity project must be built for WebGL. Alternatively, the game would need to be recreated for the browser.

What is needed next?

The original Unity project, including scenes and scripts, or an already-exported WebGL build containing index.html and its generated Build/ files.

Once a valid WebGL build is added, this landing page can be replaced with the game player.

Unofficial fan port project. Not affiliated with the original game's creators.
